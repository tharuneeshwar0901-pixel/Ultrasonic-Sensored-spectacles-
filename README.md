# Ultrasonic Sensored Spectacles 👓

## 📌 Project Overview
Ultrasonic Sensored Spectacles is an IoT-based assistive device developed to help visually impaired individuals detect obstacles while walking independently.

## 🛠 Technologies & Components Used
- Arduino UNO
- Ultrasonic Sensor (HC-SR04)
- Buzzer
- Battery Module
- Spectacle Frame
- Embedded C / Python (Arduino IDE)

## ⚙️ Working Principle
The ultrasonic sensor continuously measures the distance between the user and obstacles.
If any object is detected within a predefined range, the buzzer produces an alert sound to warn the user.

## 🎯 Objective
To improve safe mobility and independence for blind individuals using affordable IoT technology.
